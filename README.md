# 🍋 Lemon Emby Manager & Telegram Bot (EP 魔改轻量版)

> **极轻量、高颜值、全自动的 Emby 用户管理与 Telegram 智能运营中控系统**  
> 专为低内存 VPS（甚至 512MB / 1GB / 2GB 小鸡）深度优化，异步高并发，支持群内回复一键开号、一键查号、完整积分商城与抽奖经济系统、群友掷骰对决/PK/打劫游戏、卡密兑换、每日签到、到期自动封禁与多开播放实时风控。

---

## 🌟 核心特性

### 1. 🎲 积分娱乐与互动对决游戏（新升级）
- **⚔️ 群友掷骰对决 / PK（`/dice [押注]` 或 `/duel`）：**
  - **群友 PK 模式：** 引用群友消息发送 `/dice 50`，系统向对方发起决斗邀请。对方点击【⚔️ 接受对决】后双方掷骰比大小，胜者赢走押注积分！
  - **人机挑战模式：** 直接发送 `/dice 20` 与柠檬机器人比大小，赢了双倍返还。
- **🥷 积分打劫 / 劫富济贫（`/rob`）：**
  - 回复群友消息发送 `/rob`，概率掠夺目标 10%~25% 积分（带新手保护：积分 <30 不可被打劫）；若打劫失败反被当场反杀，需向受害者赔偿罚金！
- **🎰 积分幸运大转盘（`/lottery`）：**
  - 消耗 20 积分抽奖，赢取永久设备上限 +1、7 天卡、30 积分红包等丰厚大奖。

### 2. 💎 完备的积分经济与商城体系
- **每日签到领积分与时长：** `/checkin` 签到赠送时长与积分，提升群活跃度。
- **🛒 积分商城（`/shop`）：** 用户可用积分自主兑换 7天/30天/90天观影时长，或**升级并发设备限制 +1 台**。
- **💸 积分转账系统（`/transfer`）：** 支持群友间互相赠送、打赏积分。
- **🏆 积分富豪排行榜（`/rank`）：** 实时展示群内积分 TOP 10 榜单。
- **👑 管理员积分调控：** `/addpts` / `/delpts` 快速给群友发放活动奖励或扣除积分。

### 3. ⚡ 群聊极速快捷管理（支持回复触发）
- **群聊一键回复开号：** 管理员直接回复群友的消息发送 `/create 30` 或 `/open`，Bot 自动为其创建 Emby 账号，并**私聊推送服务器地址、账号密码和客户端连接指引**！
- **群聊一键回复查号：** 管理员或群友回复消息发送 `/info`，即可查询该用户的 Emby 绑定状态、到期时间、积分以及**当前正在播放的媒体和设备**。
- **一键销号：** 回复消息发送 `/deluser`，一键从 Emby 和本地数据库清理账号。

### 4. 🤖 高颜值 Telegram 原生交互
- **全 Inline Keyboard 点按式交互：** 个人中心、每日签到、积分商城、游戏大厅、节点线路一键直达。
- **自助开通与重置密码：** 用户可通过 `/bind 账号 密码` 自助开号，支持 `/resetpw` 自助改密。

### 5. 🛡️ 智能风控与多开拦截
- **并发设备数限制：** 实时监听 Emby `/Sessions`，当单个账号并发播放数超出设定的阈值时，**自动阻断多余会话并向 TG 推送拦截警告**，彻底杜绝转借号与盗刷。
- **到期自动冻结：** 巡检后台周期扫描，账号到期瞬间在 Emby 停用（保留历史数据），并在 TG 推送续期提醒；用户使用卡密后即刻全自动解封。

### 6. 🎟️ 灵活卡密与时长体系
- **批量生成卡密：** 管理员可在 TG 输入 `/gen 30 10` 批量生成 10 张 30 天时长卡，或在 Web 后台一键生成。
- **一键兑换激活：** 用户输入 `/redeem LEMON-XXXX-XXXX` 即可秒级充值并延长到期时间。

### 7. 📊 独立 Web 管理控制台
- **单文件 Dark Mode 控制面板：** 实时监控 Emby 在线状态、当前活跃播放媒体、客户端型号、IP 来源。
- **在线会话一键强踢：** 在 Web 端即可一键中断违规播放会话。
- **全异步低内存占用：** 纯 Python 异步（FastAPI + aiosqlite + aiohttp），运行时内存仅 **~20MB**。

## 🎮 Telegram 指令速查表

### 👤 普通用户指令
| 指令 | 说明 |
| :--- | :--- |
| `/start` | 打开主控面板与全功能 Inline 菜单 |
| `/my` | 查看个人账号状态、到期时间、积分与设备上限 |
| `/checkin` | 每日签到领时长与积分 |
| `/dice [押注]` | 掷骰子比大小（回复群友发起 PK 决斗，直接发挑战 Bot） |
| `/rob` | 回复群友消息进行打劫（有反杀赔款风险） |
| `/shop` | 打开积分商城，用积分兑换时长或设备上限 |
| `/lottery` | 积分幸运大转盘抽奖（20分/次） |
| `/transfer <用户> <数量>` | 积分转账给群友（支持回复消息转账） |
| `/rank` | 查看群内积分富豪排行榜 TOP 10 |
| `/bind <账号> <密码>` | 自助开通或绑定 Emby 账号 |
| `/redeem <卡密>` | 兑换卡密充值续期 |
| `/resetpw <新密码>` | 自助修改 Emby 登录密码 |
| `/info` | 查询自己的 Emby 账号档案与播放状态 |

### 👑 管理员一键特权指令
| 操作 | 触发方式 | 说明 |
| :--- | :--- | :--- |
| **一键回复开号** | **回复群友消息** 发送 `/create [天数] [密码]` | 自动提取群友 TG ID，秒开账号并私聊推送 |
| **直接开号** | `/create <用户名> [密码] [天数] [TG_ID]` | 手动指定参数开号 |
| **一键查号** | **回复群友消息** 发送 `/info` | 查询被回复群友的 Emby 状态与实时播放流 |
| **按用户名查号** | `/info <用户名或TG_ID>` | 指定关键词检索用户档案 |
| **一键销号** | **回复群友消息** 发送 `/deluser` | 彻底删除指定用户的 Emby 账号及数据 |
| **积分奖励/发放** | `/addpts <用户名/TG_ID> <点数>` | 支持回复群友发放活动积分 |
| **积分扣除** | `/delpts <用户名/TG_ID> <点数>` | 扣除指定用户的积分 |
| **批量生成卡密** | `/gen <天数> [张数]` | 批量生成兑换码，如 `/gen 30 5` |
| **查看服务器监控**| `/status` | 查看 Emby 实时负载与当前活跃播放会话 |
| **用户列表** | `/users` | 查看已登记的用户列表 |
| **手动延期** | `/addtime <用户名> <天数>` | 手动给指定用户增加有效天数 |
| **封禁/解封** | `/ban <用户名>` / `/unban <用户名>` | 手动禁用或解禁指定用户 |
