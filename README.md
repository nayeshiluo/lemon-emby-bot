# 🍋 Lemon Emby Manager & Telegram Bot (EP 魔改轻量版)

> **极轻量、高颜值、全自动的 Emby 用户管理与 Telegram 智能运营中控系统**  
> 专为低内存 VPS（甚至 512MB / 1GB / 2GB 小鸡）深度优化，异步高并发，支持群内回复一键开号、一键查号、卡密兑换、每日签到、到期自动封禁与多开播放实时风控。

---

## 🌟 核心特性

### 1. ⚡ 群聊极速快捷管理（支持回复触发）
- **群聊一键回复开号：** 管理员直接回复群友的消息发送 `/create 30` 或 `/open`，Bot 自动为其创建 Emby 账号，并**私聊推送服务器地址、账号密码和客户端连接指引**！
- **群聊一键回复查号：** 管理员或群友回复消息发送 `/info`，即可查询该用户的 Emby 绑定状态、到期时间、积分以及**当前正在播放的媒体和设备**。
- **一键销号：** 回复消息发送 `/deluser`，一键从 Emby 和本地数据库清理账号。

### 2. 🤖 高颜值 Telegram 原生交互
- **全 Inline Keyboard 点按式交互：** 个人中心、每日签到、节点线路、推荐客户端一键查询。
- **自助开通与重置密码：** 用户可通过 `/bind 账号 密码` 自助开号并绑定 TG ID，支持 `/resetpw` 自助改密。
- **签到与积分经济：** 支持每日签到领时长（如 +1 天）、攒积分，促进群聊活跃度。

### 3. 🛡️ 智能风控与多开拦截
- **并发设备数限制：** 实时监听 Emby `/Sessions`，当单个账号并发播放数超出设定的阈值（如默认 2 台）时，**自动阻断多余会话并向 TG 推送拦截警告**，彻底杜绝转借号与盗刷。
- **到期自动冻结：** 巡检后台周期扫描，账号到期瞬间在 Emby 停用（保留历史数据），并在 TG 推送续期提醒；用户使用卡密后即刻全自动解封。

### 4. 🎟️ 灵活卡密与时长体系
- **批量生成卡密：** 管理员可在 TG 输入 `/gen 30 10` 批量生成 10 张 30 天时长卡，或在 Web 后台一键生成。
- **一键兑换激活：** 用户输入 `/redeem LEMON-XXXX-XXXX` 即可秒级充值并延长到期时间。

### 5. 📊 独立 Web 管理控制台
- **单文件 Dark Mode 控制面板：** 实时监控 Emby 在线状态、当前活跃播放媒体、客户端型号、IP 来源。
- **在线会话一键强踢：** 在 Web 端即可一键中断违规播放会话。
- **全异步低内存占用：** 纯 Python 异步（FastAPI + aiosqlite + aiohttp），运行时内存仅 **~20MB**。

## 🚀 快速开始

### 方式一：Docker Compose（推荐）

1. **克隆项目并进入目录：**
   ```bash
   git clone https://github.com/nayeshiluo/lemon-emby-bot.git
   cd lemon-emby-bot
   ```

2. **配置参数：**
   ```bash
   cp config.example.yaml config.yaml
   vim config.yaml # 填入你的 Emby API Key、TG Bot Token 等
   ```

3. **一键启动：**
   ```bash
   docker compose up -d
   ```

---

### 方式二：Systemd / 本地运行

1. **安装依赖：**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **配置与启动：**
   ```bash
   cp config.example.yaml config.yaml
   # 编辑 config.yaml 后运行
   python3 main.py
   ```

## 🎮 Telegram 指令速查表

### 👑 管理员一键特权指令
| 操作 | 触发方式 | 说明 |
| :--- | :--- | :--- |
| **一键回复开号** | **回复群友消息** 发送 `/create [天数] [密码]` | 自动提取群友 TG ID 与用户名，秒开 Emby 账号并私聊推送账密与地址 |
| **直接开号** | `/create <用户名> [密码] [天数] [TG_ID]` | 手动指定参数为群友或特定 TG 开号 |
| **一键查号** | **回复群友消息** 发送 `/info` | 查询被回复群友的 Emby 状态、到期时间与实时播放流 |
| **按用户名查号** | `/info <用户名或TG_ID>` | 指定关键词检索用户档案 |
| **一键销号** | **回复群友消息** 发送 `/deluser` | 从 Emby 与数据库彻底删除被回复用户的账号 |
| **批量生成卡密** | `/gen <天数> [张数]` | 批量生成兑换码，如 `/gen 30 5` |
| **查看服务器监控**| `/status` | 查看 Emby 实时负载与当前活跃播放会话 |
| **用户列表** | `/users` | 查看已登记的用户列表 |
| **手动延期** | `/addtime <用户名> <天数>` | 手动给指定用户增加有效天数 |
| **封禁/解封** | `/ban <用户名>` / `/unban <用户名>` | 手动禁用或解禁指定用户 |

### 👤 普通用户指令
| 指令 | 说明 |
| :--- | :--- |
| `/start` | 打开主控面板与 Inline 菜单 |
| `/my` | 查看个人账号状态、到期时间、积分 |
| `/checkin` | 每日签到领时长与积分 |
| `/bind <账号> <密码>` | 自助开通或绑定 Emby 账号 |
| `/redeem <卡密>` | 兑换卡密充值续期 |
| `/resetpw <新密码>` | 自助修改 Emby 登录密码 |
| `/info` | 查询自己的 Emby 账号档案与播放状态 |
